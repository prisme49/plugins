# _ADD : boîte de dépôt

Déposez ici tout document que l'agent doit prendre en compte (notes, exports, contrats, images, captures...).

Au prochain démarrage de session (compétence start), ou sur demande (« j'ai mis des documents dans _ADD, traite-les »), l'agent traite chaque pièce : il crée sa fiche markdown dans _DOCS/ (résumé, description, frontmatter), range l'original dans _DOCS/pieces/, régénère l'index, ou classe dans le livrable du projet si c'est du fond. Ce dossier doit finir vide.

Hors Git.
