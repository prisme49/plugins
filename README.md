# Plugins de Cyril Verglas pour Claude

Marketplace publique de plugins pour Claude Code, l'application de bureau Claude et Cowork.

## Installer

En ligne de commande :

```bash
claude plugin marketplace add prisme49/plugins
claude plugin install go@prisme49
```

Dans l'application : Personnalisation, Plugins, Ajouter, depuis un dépôt GitHub : `prisme49/plugins`.

## Les plugins

| Plugin | Rôle |
| --- | --- |
| go | Le kit qui donne une mémoire à vos projets menés avec des agents IA : rituels de début et de fin de session, checkpoints de décision, courrier inter-agents, documentation, images, extinction du poste. |

Les nouveautés de chaque version sont dans `plugins/<nom>/RELEASES.md`.

Ce dépôt est une vitrine générée : les plugins sont développés ailleurs et recopiés ici à chaque livraison. Ne pas y proposer de modification directe.
